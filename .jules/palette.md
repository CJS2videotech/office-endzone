## 2024-05-18 - Interactive Elements Require Keyboard Handlers and Focus Styles
**Learning:** Adding `tabindex="0"` and `role="button"` makes an element keyboard-focusable, but standard native keys like `Enter` or `Space` do not automatically trigger click handlers on generic tags like `div`. Explicit `keydown` event handlers must be added to listen to `Enter` and `Space`. Furthermore, `:focus-visible` styling must be added to visual focus indicators; otherwise users cannot tell which item is focused. When applying keydown events on parent container for delegation, you should ensure that `e.target` matches the focused container, so that hitting `Enter` inside child focusable elements doesn't erroneously trigger the parent event.
**Action:** Always test new interactive `role="button"` elements via keyboard to ensure both the visual focus outline acts correctly and `Enter`/`Space` actually activate the desired behavior.
